# 印刷交接

先明确成品最长边、数量、面材和是否整版半断。历史规格为 50 mm 整版贴纸和 90 mm 独立透明贴纸，可作为讨论起点。

有效分辨率以实际像素除以图案的印刷英寸尺寸计算。保留原生像素，记录尺寸和有效 dpi。PNG 透明背景和白色脑部、手套、鞋面需要区别处理。

向打印店分别提供彩色图案、矢量闭合外刀线、带刀线校样和白墨参考。悬浮符号需与角色合并为同一枚可揭取轮廓。黄色离型底纸由材料决定。透明面材上的白色区域通常需要白墨，由店内 RIP 配置专色和缩边。

普通 PDF 阅读器显示白色页面时，通过透明 PNG 或 PDF 渲染的 Alpha 检查实际背景。刀线颜色只出现在技术文件与校样中。打印文件按 100% 实际尺寸输出，颜色转换遵循打印设备的 ICC 配置。

本仓库的渲染脚本交付单张创作素材。用户要求印刷时，继续完成其所需排版和技术分版，检查最终 PDF 渲染及实际页数，并建议用实物样确认小字和白墨效果。
