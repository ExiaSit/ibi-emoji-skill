# 合成参数

依赖 Python 3.10 或更新版本、Pillow、CairoSVG 及系统 Cairo。安装方式见 README。

`foreground` 相对于场景 JSON 所在目录解析。输出路径由 `--output` 指定。`--example 22` 从安装包读取该实例的场景，适合先检查环境。

```json
{
  "foreground": "foreground.png",
  "body_box_norm": [0.15, 0.04, 0.70, 0.77],
  "rotation": 0
}
```

| 字段 | 含义 |
| --- | --- |
| `foreground` | RGBA PNG 前景路径 |
| `body_box_norm` | 身体整体的左上角 x、y、宽、高，各除以前景画布宽或高 |
| `rotation` | 整个身体围绕身体框中心旋转的角度，SVG 正角度为顺时针 |
| `body_clip_y_norm` | 可选的身体显示区域下边界，默认 1，用于被子等遮挡场景 |
| `behind_body_rects` | 可选的归一化矩形列表，指定前景中应置于身体后面的区域，常用于腿部连接 |

身体框可以超出画布，交付前需检查裁切是否符合构图。宽高可改变以适应二维姿态，优先维持母版的长宽比，明显的拉伸会同时改变校徽形状。

14 号实例使用 `behind_body_rects` 把两条腿的上部放到身体后面。检查眼睛是否落在合适区域、腕部和腿部是否相接，再调整身体框或前景组件。校徽位置由唯一母版决定。

脚本输出 `name.png`、`name.svg`、`name.preview.png` 和 `name.json`。制作记录包含规范化场景参数、母版与前景的 SHA-256、画布尺寸以及输出文件校验值。SVG 内嵌完整母版和前景，可独立打开。

脚本默认保护已有输出。确认需要覆盖同一作品后使用 `--force`。母版校验失败时，先判断素材是否损坏或曾被显式重新设计，再恢复正确版本或更新经过审核的新母版版本。
